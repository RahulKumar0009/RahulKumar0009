## 🛠️ Featured Project

### 🚗 Vehicle Resale Value Predictor — 2-Wheeler & 4-Wheeler
> *A voice + text conversational AI that predicts resale prices using ML*

**Stack:** `Python` `FastAPI` `Random Forest` `scikit-learn` `Whisper STT` `pyttsx3` `gTTS` `Docker` `pandas` `NumPy` `joblib`

- 🎙️ Built a **voice + text Q&A assistant** similar to Alexa — using Whisper STT for input and pyttsx3/gTTS for speech output
- 💰 Dual-price prediction — estimates both **dealer/showroom price** and **private sale price** from a single model via a `sale_channel` feature
- 📊 Trained on **12,000+ synthetic records** with a Random Forest Regression model
- 🐳 Fully containerized with **Docker Compose** — separate containers for data generation, training, and the main app
